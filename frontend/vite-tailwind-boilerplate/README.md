# Vite + Tailwind Minimal Boilerplate

This folder hosts a minimal Vite + Tailwind setup mirrored from the existing `user-app` dependencies.

## Getting Started

1. Install dependencies:
   ```bash
   cd vite-tailwind-boilerplate
   npm install
   ```
2. Run the dev server:
   ```bash
   npm run dev
   ```

## Features

- React 19 + Vite 7, Tailwind CSS 3.
- Space Grotesk typography and an accent color for quick styling.
- Ready-made layout shell in `src/App.jsx`.
